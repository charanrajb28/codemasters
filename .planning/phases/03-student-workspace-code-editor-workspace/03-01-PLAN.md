# Plan 03-01: Student Problem Catalog & Student Server Actions

## Goal
Build the student problem catalog page (`/problems`) featuring a structured table layout with search query input, difficulty filters, category tag pills, solved status indicators, and student-facing Server Actions.

## Context
- **Catalog Layout**: Problem catalog at `/problems` rendered as a clean structured table with top search bar and filter pills. Columns: Solved Status indicator (`✓ Solved`, `⚡ Attempted`, `—`), Problem Title (link to workspace `/problems/[slug]`), Difficulty badge (`Easy` green, `Medium` yellow, `Hard` red), Category Tags, and Acceptance Rate %.
- **Multi-Criteria Filtering**: Support real-time text search, Difficulty filter (`All`, `Easy`, `Medium`, `Hard`), Category/Tag filter, and Solved Status filter (`All`, `Unsolved`, `Solved`).
- **Server Actions**: `src/actions/student-actions.ts` handling problem list fetching with user completion status, problem details retrieval, sample test runner execution, solution submission creation, status polling, and submission history retrieval.
