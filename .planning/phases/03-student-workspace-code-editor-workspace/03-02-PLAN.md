# Plan 03-02: Split-Pane Workspace, Monaco Editor & Submission Pipeline

## Goal
Build the student code editor workspace (`/problems/[slug]`) featuring a responsive split-pane layout, Monaco editor with multi-language support (Python, C++, Java, JavaScript) and local draft saving, interactive sample test runner drawer with stdout/stderr diff view, real-time submission evaluation pipeline UI, and submission history log with code inspection.

## Context
- **Split-Pane Layout**: Left pane with tabs `[Description, Submissions, Editorial]`. Right pane with Top Action Bar (Language selector, Reset code, Monaco editor `vs-dark`) + collapsible bottom drawer for `[Test Cases, Test Results]`.
- **Monaco Editor**: Integrated `@monaco-editor/react` with default starter templates per language (Python, C++, Java, JavaScript) and browser `localStorage` draft saving.
- **Sample Test Runner Drawer**: Tabbed sample test cases (`Case 1`, `Case 2`, `+ Custom Input`), Passed/Failed badges, actual vs expected output diff comparison, stdout/stderr log output, and execution time (ms).
- **Submission Pipeline UI**: Submit button animated loading state (`Queued...` ➔ `Running...`), Verdict Card (`Accepted`, `Wrong Answer`, `TLE`, etc.) with test cases passed counter (e.g. `15/15`).
- **Submission History**: Submissions tab listing past attempts with verdict badges, time, memory, and modal viewer for exact submitted code.
