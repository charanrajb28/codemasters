# Phase 2: Admin Portal & Problem Authoring Suite - Context

**Gathered:** 2026-09-18
**Status:** Ready for planning

## Phase Boundary

Deliver a comprehensive Admin Portal accessible at `/admin/*` featuring an interactive User Management table (RBAC role changes, account suspension toggle, search & filter), a Problem Authoring Suite with a Split-Pane Markdown Editor, a Test Case Manager supporting JSON/batch upload & hidden test case flags, and an Executive System Telemetry Dashboard displaying KPI stat cards and Recharts analytics.

<decisions>
## Implementation Decisions

### User & Access Management (ADMIN-01)
- **D-01:** **Interactive User Table**: Server-side user search and role filter (`STUDENT` vs `ADMIN`). Table columns: Name, Email, Role, Status (`Active` vs `Suspended`), Created Date, Actions.
- **D-02:** **Role & Suspension Controls**: Instant Server Action dropdown for changing user role (`STUDENT` ↔ `ADMIN`) and a one-click button to toggle `isSuspended` flag with optimistic UI updates.

### Problem Authoring Suite (ADMIN-02)
- **D-03:** **Problem CRUD Interface**: Admin routes for `/admin/problems` (list & search), `/admin/problems/new` (create), and `/admin/problems/[id]/edit` (update).
- **D-04:** **Split-Pane Markdown Description Editor**: Left pane featuring raw markdown textarea; right pane rendering live formatted HTML preview (headers, code blocks, lists, constraints).
- **D-05:** **Problem Metadata**: Form fields for Title, Slug (auto-generated), Difficulty (`Easy`, `Medium`, `Hard`), Time Limit (ms, default 2000), Memory Limit (MB, default 256), and Tags (`Arrays`, `Graphs`, `DP`, etc.).

### Test Case Management (ADMIN-03)
- **D-06:** **Batch & JSON Test Case Import**: Dual input mode: 1) Interactive row editor for individual test cases (Input textarea, Expected Output textarea, `isHidden` checkbox), and 2) Batch JSON File / Text Upload parser for bulk adding test cases.
- **D-07:** **Hidden Test Case Security**: Evaluation test cases flagged as `isHidden: true` are stored securely and never transmitted to student client responses.

### Telemetry & Metrics Dashboard (ADMIN-04)
- **D-08:** **Telemetry Grid**: Top KPI summary cards for Total Submissions, Overall Acceptance Rate %, Active Users Count, and Kubernetes Runner Queue Health.
- **D-09:** **Recharts Analytics**: Visual charts for Verdict Distribution (Donut chart for Accepted, Wrong Answer, TLE, MLE, Error) and Daily Submission Volume (Bar chart).

### Claude's Discretion
- Form state management details and toast notification messages.
- Specific Recharts color tokens matching the Midnight Monochrome design system (`#ffffff`, `#a3a3a3`, `#10b981`, `#ef4444`, `#f59e0b`).

</decisions>
