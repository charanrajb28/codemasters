# Plan 02-02: Problem Authoring Suite & Test Case Manager

## Goal
Build the Problem Management CRUD suite with a Split-Pane Markdown Editor and a Test Case Manager supporting both interactive row editing and JSON/Batch file import with hidden test case flags.

## Context
- **Problem Authoring**: CRUD routes at `/admin/problems`, `/admin/problems/new`, `/admin/problems/[id]/edit`. Split-pane markdown description editor (raw markdown left, live formatted preview right).
- **Test Cases**: Tabbed/batch test case manager supporting individual row input and bulk JSON file upload. Security flags ensure `isHidden: true` test cases are never transmitted to student clients.
- **Reference Context**: `.planning/phases/02-admin-portal-problem-authoring-suite/02-CONTEXT.md`
