# Phase 2: Admin Portal & Problem Authoring Suite - Technical Research

## Objective
Investigate and document technical patterns for building the Admin Portal dashboard, Recharts analytics, user RBAC management table, split-pane markdown problem editor, and batch test case importer.

## Technical Patterns & Stack Selections

### 1. Recharts Analytics in Next.js App Router
- **Component Pattern**: Recharts relies on DOM APIs (SVG element measurements) and must be rendered in Client Components (`"use client";`).
- **Charts to Build**:
  - `VerdictChart`: `PieChart` / `Pie` with custom colors (`#10b981` Accepted, `#ef4444` Wrong Answer, `#f59e0b` TLE/MLE, `#6b7280` Error).
  - `VolumeChart`: `BarChart` / `Bar` showing daily submission activity over 7 days.
- **Responsive Wrapper**: Wrap charts in `<ResponsiveContainer width="100%" height={300}>`.

### 2. Split-Pane Markdown Editor
- Left Pane: `<textarea>` styled with Midnight Monochrome tokens (`var(--bg-card)`, `var(--border-color)`, monospace font).
- Right Pane: Markdown rendering component converting headers (`#`, `##`), lists, code blocks (` ``` `), and bold text into styled DOM elements.

### 3. User & Access Management Server Actions
- File: `src/actions/admin-actions.ts`

### 4. Problem & Test Case Batch Management
- File: `src/actions/problem-actions.ts`
- Functions:

- Database Transaction: Wrap problem creation and test case insertion in `prisma.$transaction()` to ensure atomicity.

## Gotchas & Risk Mitigations
1. **Recharts SSR Hydration Warning**:
   - *Issue*: Recharts `ResponsiveContainer` evaluates container dimensions on client, causing React hydration mismatches if server renders dummy dimensions.
   - *Fix*: Render Recharts components dynamically or inside a mounted state check (`const [mounted, setMounted] = useState(false); useEffect(() => setMounted(true), []); if (!mounted) return <Skeleton />`).
2. **Hidden Test Cases Client Exposure**:
   - *Issue*: Fetching problem test cases via a public API route might expose hidden evaluation test cases to student network tabs.
   - *Fix*: Filter out `isHidden: true` test cases in all public student query functions (`prisma.testCase.findMany({ where: { problemId, isHidden: false } })`). Only admin actions (`/admin/*`) or backend worker services can query hidden test cases.
