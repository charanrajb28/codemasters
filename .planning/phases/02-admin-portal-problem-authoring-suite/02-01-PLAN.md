# Plan 02-01: User Management & System Telemetry Dashboard

## Goal
Build the User Management RBAC table with server-side search, role change dropdowns, and suspension toggles, alongside the Executive Telemetry Dashboard featuring KPI stat cards and Recharts analytics.

## Context
- **User Management**: Server-side user search and role filter (`STUDENT` vs `ADMIN`). Direct role elevation dropdown and one-click account suspension toggle with optimistic UI updates.
- **Telemetry**: KPI summary cards (Total Submissions, Acceptance Rate %, Active Users, K8s Queue Status) and Recharts charts for Verdict Distribution (Donut) & Daily Submission Volume (Bar).
- **Reference Context**: `.planning/phases/02-admin-portal-problem-authoring-suite/02-CONTEXT.md`
