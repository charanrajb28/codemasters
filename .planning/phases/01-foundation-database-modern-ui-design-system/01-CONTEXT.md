<decisions>
## Implementation Decisions

### Visual Theme & UI Aesthetics
- **D-01:** **Midnight Monochrome Palette**: Deep black background (`#000000`), sharp high-contrast white borders, monochromatic grayscale accents, crisp typography, subtle hover transitions.
- **D-02:** **Layout Structure**: Collapsible Left Sidebar navigation + Top Action Bar (optimal for switching between Student Code Editor workspace and Admin Portal controls).
- **D-03:** **Design Tokens**: Centralized CSS custom properties in `src/styles/globals.css` defining monochrome tokens, glassmorphism overlays, and border radii.

### Authentication & Authorization (RBAC)
- **D-04:** **Dedicated Auth Interface**: Standalone `/login` and `/register` pages featuring glassmorphic centered cards with responsive layouts.
- **D-05:** **Session & Role Middleware**: Auth.js / NextAuth with JWT strategy + Prisma adapter. Next.js middleware enforcing RBAC (`STUDENT` vs `ADMIN` roles) on protected routes (`/admin/*`, `/workspace/*`).
- **D-06:** **Default Seed Credentials**: Database seed script populates default admin account (`admin@dsa.local` / `admin123`, role: `ADMIN`) and student account (`student@dsa.local` / `student123`, role: `STUDENT`).

### Database & Component Architecture
- **D-07:** **Prisma & PostgreSQL**: PostgreSQL schema modeling `User`, `Account`, `Session`, `Role` (ENUM: `STUDENT`, `ADMIN`), `Problem`, `TestCase`, and `Submission`.
- **D-08:** **Reusable UI Primitives**: Modular component primitives built under `src/components/ui/` (Button, Input, Card, Modal, Badge, Table, Sidebar, TopNav).

### Claude's Discretion
- Form validation schemas (Zod) and error message toast patterns.
- Specific icon selections (Lucide React icons).

</decisions>
