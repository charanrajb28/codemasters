# Phase 1: Foundation, Database & Modern UI Design System - Technical Research

## Objective
Investigate and define standard technical patterns for initializing Next.js 15 App Router, Prisma ORM with PostgreSQL, Auth.js (NextAuth.js v5) RBAC authentication, and the Midnight Monochrome CSS design system.

## Key Technical Patterns & Stack Selections

### 1. Next.js 15 App Router & Project Structure
- Standard layout architecture:
  - `src/app/layout.tsx`: Root layout with dark mode background (`#000000`), global CSS imports, and Font configuration.
  - `src/app/(auth)/login/page.tsx` & `/register/page.tsx`: Auth layout route group with centered glassmorphic card container.
  - `src/app/(dashboard)/layout.tsx`: Collapsible Left Sidebar + Top Action Bar container for authenticated views.
  - `src/components/ui/`: Reusable UI primitives (Button, Input, Card, Modal, Badge, Sidebar, TopNav).
  - `src/lib/`: Database clients (`prisma.ts`), authentication configurations (`auth.ts`), password hashing (`password.ts`).

### 2. Database Schema & Prisma ORM setup
- Schema models in `prisma/schema.prisma`:
  - `Role` enum: `STUDENT`, `ADMIN`
  - `User`: `id`, `name`, `email`, `passwordHash`, `role`, `isSuspended`, `createdAt`, `updatedAt`
  - `Account`, `Session` (Auth.js compatibility)
  - `Problem`, `TestCase`, `Submission` (placeholders for Phases 2-4)
- Database Seed script (`prisma/seed.ts`):
  - Uses `bcryptjs` or `argon2` for hashing default admin & student passwords.
  - Creates `admin@dsa.local` (`ADMIN` role) and `student@dsa.local` (`STUDENT` role).

### 3. Auth.js (NextAuth v5) & RBAC Middleware
- Edge-compatible session middleware in `src/middleware.ts` checking JWT roles for `/admin/*` routes.
- NextAuth configuration separated into `auth.config.ts` (Edge safe for middleware) and `auth.ts` (Prisma adapter for Node runtime).
- Server Actions in `src/actions/auth-actions.ts` for handling login and registration credentials.

### 4. Midnight Monochrome CSS Design System
- CSS Variables defined in `src/styles/globals.css`:
  - `--bg-primary`: `#000000`
  - `--bg-surface`: `#0a0a0a`
  - `--bg-card`: `#121212`
  - `--border-color`: `#262626`
  - `--border-bright`: `#404040`
  - `--text-primary`: `#ffffff`
  - `--text-secondary`: `#a3a3a3`
  - `--accent-monochrome`: `#e5e5e5`
- Glassmorphism & Micro-animations:
  - Subtle `backdrop-filter: blur(12px)` overlays for floating panels.
  - `transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)` for button hovers and sidebar collapse state.

## Gotchas & Risk Mitigations
1. **NextAuth Edge Middleware with Prisma**:
   - *Issue*: Prisma Client uses Node.js native APIs which cannot run directly in Next.js Edge Middleware.
   - *Fix*: Split Auth.js config into `auth.config.ts` (uses JWT callbacks & routes without DB adapter) for middleware, and `auth.ts` (uses Prisma adapter & credentials provider) for Node runtime.
2. **PostgreSQL Connection Exhaustion in Next.js**:
   - *Fix*: Instantiate Prisma Client as a global singleton (`globalThis.prisma`) in `src/lib/prisma.ts` to prevent database connection leaks during Next.js hot-reloads.
