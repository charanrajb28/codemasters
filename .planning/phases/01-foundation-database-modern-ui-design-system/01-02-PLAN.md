# Plan 01-02: PostgreSQL Prisma ORM, Auth.js RBAC, Seed Script & Dedicated Auth Interfaces

## Goal
Establish the Prisma ORM PostgreSQL schema for user accounts & RBAC roles, build database auto-seeding for default Admin and Student accounts, configure Auth.js (NextAuth v5) with JWT session management & middleware route protection, and create dedicated `/login` and `/register` glassmorphic authentication pages.

## Context
- **Database & Roles**: Prisma schema modeling `User`, `Role` (`STUDENT`, `ADMIN`), `Account`, `Session`, `Problem`, `TestCase`, `Submission`.
- **Seed Credentials**: `admin@dsa.local` (`admin123`) & `student@dsa.local` (`student123`).
- **Auth Interface**: Dedicated `/login` and `/register` pages with centered glassmorphic card containers.
- **Reference Context**: `.planning/phases/01-foundation-database-modern-ui-design-system/01-CONTEXT.md`
